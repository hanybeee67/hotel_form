거성호텔 나이트 마감 도우미 — 사용법
=====================================

[카카오톡으로 옮기기]
1. GitHub에서 받은 GeoseongClosingTool.zip 을 압축을 풀지 않은 채로
   카카오톡 PC '나와의 채팅'에 보냅니다. (exe 파일만 따로 보내면 카카오톡이 막을 수 있습니다)
2. 호텔 PC의 카카오톡 PC 버전에서 파일을 저장합니다.
   (기본 저장 위치: 문서 → 카카오톡 받은 파일)
3. zip 파일을 마우스 오른쪽 → [압축 풀기] 한 뒤, 풀린 폴더를 바탕화면 등으로 옮깁니다.

[설치]
1. 이 폴더(GeoseongClosingTool) 전체를 호텔 PC의 바탕화면 등에 복사합니다.
   - GeoseongClosingTool.exe 와 config.json 은 반드시 같은 폴더에 둡니다.
   - templates 폴더(호텔 빈 양식)가 있으면 그것도 같은 폴더에 둡니다.
2. GeoseongClosingTool.exe 를 더블클릭합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.

[사용]
1. 맨 위 '영업일자'를 확인합니다. (정오 전에는 전날이 자동 선택, ◀ ▶ 로 하루씩 변경)
2. ERP에서 '엑셀전환'으로 저장한 파일을 서류 카드의 [파일 선택]으로 고릅니다.
   - 여러 파일을 한 번에: [모든 서류 한 번에 변환] → Ctrl+클릭으로 여러 개 선택
3. 결과는 이 프로그램이 들어 있는 폴더(예: 한희 폴더) 안의 '마감결과' 폴더에 저장됩니다.
   - 카드의 [결과 열기] 또는 [결과 폴더 열기]로 바로 열 수 있습니다.
4. 결과는 엑셀(.xlsx) 파일입니다. 열어서 노란 칸을 직접 확인·입력한 뒤 저장(Ctrl+S)합니다.
   - 수입일보: 선/후(목록에서 '선'/'후' 선택). 숙박수는 출발일-도착일로 자동 입력(날짜가 없으면 노란 칸)
     ROOM 다음에 Extra-Charge · 1회용품 · 조식 · 연회가 차례로 붙고, 묶음마다 '계'(앞 묶음까지 합산) → 마지막 계 = ERP '계'
     숙박수 = 이번 달 들어 오늘까지 묵은 날 수(자동), 누계 = 매출 × 숙박수(수식). 숙박수를 고치면 누계도 자동으로 바뀝니다
   - 카드 승인내역: 객실(오른쪽 Acct# 참고), 현금영수증이 노란 칸이면 금액
     ERP와 연동 안 되는 한벽루 단말기 승인 건은 현금영수증 줄 위 노란 빈 줄 4개에 적습니다(계에 자동 포함). 승인 실패 건은 자동으로 빠집니다
   - 조식명단: Sign 칸은 손님 서명용으로 비워 둡니다.
   - 합계(계)·누계는 수식이라 숫자를 고치면 자동으로 다시 계산됩니다.
   - 노란색은 화면 안내용이라 인쇄하면 나오지 않습니다(흑백 인쇄 설정).
5. '작업 기록'에 주황색 '확인' 문구가 있으면 꼭 읽어 봅니다.

[5번 조식 인원수 (저녁 8시 보고용)]
- 아직 체크인 안 한 손님은 IN HOUSE LIST에 없어 조식 인원이 빠지기 쉽습니다. 이 버튼은 두 파일을 합쳐 내일 아침 인원만 셉니다.
- [파일 2개 선택] → ① IN HOUSE LIST → ② 객실 예약 리스트(오늘 도착 손님이 보이게 받은 파일) 순서로 고릅니다.
- 영업일자 = 오늘(저녁 근무일)이면 '다음 날 아침' 인원이 나옵니다. 창에 합계가 뜨고, '조식인원 날짜.xlsx'에 객실별 목록이 저장됩니다.
- 이미 체크인한 손님(예약상태 '투숙', 같은 객실·이름)은 한 번만, 취소·노쇼·룸온리는 빼고 셉니다.
- 조식명단(4번) 자체는 새벽에 IN HOUSE LIST로 만들면 됩니다.

[실행이 안 될 때 (공용폴더·한희 폴더에서)]
1. exe를 마우스 오른쪽 → [속성] → 아래쪽 '차단 해제'에 체크 → [확인] 후 다시 실행
   (카카오톡으로 받은 파일은 Windows가 막아 둘 수 있습니다. zip 파일도 압축 풀기 전에 똑같이 '차단 해제')
2. "접근할 수 없습니다"가 나오면: 회사 보안 설정·백신이 공용폴더에서의 실행을 막는 것입니다.
   → 폴더째 '바탕 화면'에 복사해서 실행하세요.
   → 프로그램의 [저장 위치 변경]을 눌러 공용폴더의 '한희' 폴더를 한 번 골라 두면,
     바탕화면에서 실행해도 결과는 계속 한희\마감결과에 저장됩니다 (이 PC가 기억함).
3. 프로그램 폴더에 저장할 권한이 없으면 결과는 자동으로 '문서\마감결과'에 저장되고, 작업 기록에 알려 줍니다.
4. 오류 창이 뜨면 프로그램 폴더(또는 문서\마감결과)의 '오류기록.txt'를 담당자에게 보내 주세요.

[문제가 생기면]
- "결과 파일이 엑셀에서 열려 있습니다" → 엑셀에서 그 파일을 닫고 다시 변환
- "필수 항목을 찾지 못했습니다" → 다른 서류 파일을 고른 것인지 확인
- 그 밖의 오류는 작업 기록의 빨간 문구를 그대로 담당자에게 전달해 주세요.
