# 호텔 양식(템플릿)

> 2026-10-23: 호텔 실제 마감 파일 4종에서 서식만 뽑아 만든 빈 양식이 들어 있습니다 (`tools/make_templates.py`). 개인정보 없음.

이 폴더에 아래 **이름 그대로** 호텔 빈 양식 엑셀을 넣으면, 변환 결과가 양식의 폰트·글자 크기·열 너비·행 높이·병합·인쇄 설정을 그대로 따릅니다.
파일이 없으면 `config.json`의 `font` 값(사진으로 추정한 값)으로 만듭니다.

| 서류 | 파일 이름 |
|---|---|
| 수입일보 | `수입일보.xlsx` |
| 카드/현금영수증 승인내역 | `카드승인내역.xlsx` |
| 대외후불 리스트 | `대외후불리스트.xlsx` |
| 조식명단 | `조식명단.xlsx` |

## 빈 양식 만드는 법 (개인정보 지우기)
1. 지난 날짜의 호텔 마감 파일을 복사해서 위 이름으로 바꿉니다.
2. 시트가 여러 개면 **한 장만 남기고** 지웁니다.
3. **제목 행, 열 제목 행, 첫 번째 데이터 행, `계` 행**만 남기고 나머지 데이터 행은 행 삭제합니다.
4. 남긴 첫 번째 데이터 행과 `계` 행은 칸을 선택해 **Delete 키로 내용만** 지웁니다(테두리·글꼴은 남겨야 합니다).
5. 이름·카드번호·사업자번호 등 개인정보가 하나도 없는지 확인하고 저장합니다.

프로그램은 열 제목(객실, 고객명 …)으로 칸을 찾으므로, 열 제목은 바꾸지 마세요.
exe로 쓸 때는 `GeoseongClosingTool.exe` 옆에 `templates` 폴더째로 둡니다.
